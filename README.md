教育内容与视频一体化创作工作室，把主题、题目、课堂录音、逐字稿、教材或课程素材加工成可教学、可学习、可评量的内容。按你的目标走最小充分的交付路径：要学概念就出学习目标、先备知识、分步讲解、例题与检查理解；要备课就出教案、板书/课件结构、课堂活动、时间分配与教师提示；要练习考试就出题目、难度梯度、答案、解析、评分标准与错因标签；要微课就出旁白稿、镜头表、字幕、资产清单与音画节奏。先把内容完整的逐字旁白写出来，再按受众基准语速、有效字数和标点/呼吸停顿算出自然发声时长，并弹确认卡让你选择接受、加时长或减时长。所有阶段性产物都要写入画布节点才算交付，Brief 是硬门。

- 备课路线产出教案、板书/课件结构、课堂活动、时间分配与教师提示；练习路线产出题目、难度梯度、答案、解析、评分标准与错因标签

## 🇬🇧 English

An end-to-end educational content and video studio that turns a topic, question, class recording, transcript, textbook or course material into content that can be taught, learned or assessed. It takes the smallest sufficient delivery path for your goal: learning a concept yields objectives, prerequisite knowledge, step-by-step explanation, worked examples and comprehension checks; lesson prep yields a lesson plan, board/slide structure, classroom activities, timing and teacher notes; practice and exams yield questions, difficulty gradients, answers, explanations, grading criteria and error-cause tags; micro-lessons yield narration scripts, shot lists, subtitles, asset lists and audio-visual pacing. It drafts a complete verbatim narration first, then derives natural spoken duration from the audience's baseline speech rate, effective character count and punctuation/breath pauses. Staged outputs count as delivered only once written into canvas nodes, and a written Brief is a hard gate.

### ✨ What it does

- Topic, question, class recording, transcript or textbook → up to 3 learning objectives, prerequisite knowledge, step-by-step explanation, worked examples and comprehension checks
- Lesson-prep route yields lesson plan, board/slide structure, classroom activities, timing and teacher notes; practice route yields questions, difficulty gradient, answers, explanations, grading criteria and error-cause tags
- Micro-lesson route yields verbatim narration, shot list, subtitles, asset list and pacing, with narration written into each video prompt alongside on-screen events
- Writes the full verbatim narration first, then computes natural spoken duration from baseline speech rate, effective character count and punctuation/breath pauses, offering an accept / more seconds / fewer seconds choice
- When over budget it may only cut repetition, merge adjacent meaning or split into a series — never by speeding up speech, deleting pauses or editing only the video duration
- Staged outputs count only when written as canvas nodes (Brief.md, video script & prompts, storyboards/keyframes, video clips, VO/music/SFX, editable cut, final render)
